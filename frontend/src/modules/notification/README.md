# Notification Module

Responsibilities:

- auth notifications
- approval notifications
- order and payout alerts
- in-app notification presentation

Current App Router coverage:

- security notification preview for login and registration flows
- lock, reset, approval, and new-device event foundations
- operational automation panel for delivery, commission, reporting, and store administration surfaces
- service-side event map is documented in `backend/apps/notification-service/AUTH_EVENTS.md`
- service-side operations event map is documented in `backend/apps/notification-service/OPERATIONS_AUTOMATION_EVENTS.md`
