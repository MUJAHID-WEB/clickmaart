# Notification Service

Responsibilities:

- SMS notifications
- email notifications
- in-app alerts
- event subscription and fan-out
- delivery of auth, approval, order, payout, and system alerts

Planning docs:

- `AUTH_EVENTS.md` lists the login, OTP, lock, new-device, and approval notification events needed by identity flows.
- `OPERATIONS_AUTOMATION_EVENTS.md` lists the Phase 7 order, delivery, payout, store, and export notification events.
