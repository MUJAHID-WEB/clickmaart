# Order Orchestration Service

Responsibilities:

- order placement
- lifecycle stage transitions
- pending to payment-done workflow
- external marketing orders
- storefront orders
- dispute and damage flags

- `WHOLESALER_FULFILLMENT_CONTRACT.md` contains the Phase 4 wholesaler fulfillment API draft.
- `RETAILER_ORDER_TRACKING_CONTRACT.md` contains the Phase 5 retailer order and delivery tracking API draft.
- `FULL_ORDER_MANAGEMENT_CONTRACT.md` contains the Phase 7 multi-party order orchestration API draft.
